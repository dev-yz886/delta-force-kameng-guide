## 一、 发卡产业链角色与拓扑术语拆解

在虚拟商品分发网络中，各节点分工明确：
1. **货源总站（Primary Hub）**：真正持有虚拟商品库存与批量生成权限的主控端系统；
2. **加盟分站（Affiliate Sub-site）**：仅具备商品展示与前端收款功能，通过 API 对接总站的代理站点；
3. **提卡密码（Retrieval Key）**：用户在未注册状态下，用于在订单大厅提取虚拟密钥的一串自定义凭证。

## 二、 卡密生命周期与状态转换流程

一张正规三角洲行动卡盟的数字卡密在系统内遵循严格的状态机流转：

```text
[生成入库] -> [未售锁定: Locked] -> [付款成功: Paid] -> [密钥交付: Dispatched] -> [核销作废: Consumed]
```

任何未经验证直接变更为废止状态的卡密均属于系统异常，商户端需具备自动审计日志。
